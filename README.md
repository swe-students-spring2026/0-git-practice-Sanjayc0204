# Sanjay Chunduru Git Practice Assignment

### Article
Here is the article I picked, called [When AI writes almost all code, what happens to software engineering?](https://newsletter.pragmaticengineer.com/p/when-ai-writes-almost-all-code-what)

### Writeup

I picked this text because it fearlessly says the quiet part out loud (namely, that software engineering as a profession is evolving into something that current software engineers or students may not necessarily like) and analyzes what a world where code is primarily AI-driven would look like.

The article particularly resonates because it doesn't just present AI as another tool in the developer's toolkit, but rather as a fundamental shift that could redefine the entire value proposition of software engineers. It explores how the focus might move from writing code to problem decomposition, system design, and verification—skills that become exponentially more valuable when AI handles the implementation details. Particularly, this perspective challenged me to think put aside my reservations, emotions, and thoughts about what the world ought to be and instead critically think about what aspects of our work are truly irreplaceable and how we might adapt our skills and career expectations to remain relevant in an AI-augmented future.
